# Hacker Terminal Simulator - Документация

## Описание проекта

Hacker Terminal Simulator - это стимулятор хакерского терминала с эффектом "матричного дождя" из двоичного кода. Проект создан для погружения в атмосферу киберпанка и хакерских операций.

## Особенности

- ✅ Реалистичный интерфейс командной строки
- ✅ Анимация падающего двоичного кода (эффект "матрицы")
- ✅ Интерактивные команды с историей
- ✅ Система прогресс-бара для длительных операций
- ✅ Пагинация для просмотра длинных выводов
- ✅ Автоматическое скрытие прогресс-бара после завершения
- ✅ Черно-белая цветовая схема в стиле терминалов

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/hacker-terminal.git
cd hacker-terminal
```

2. Установите зависимости:
```bash
pip install pygame
```

3. Поместите файл шрифта `couriernew.ttf` в папку `fonts/`

## Запуск

```bash
python main.py
```

## Управление

- Вводите команды в строке ввода (появляется после символа `>`)
- Нажимайте `Enter` для выполнения команды
- Используйте `Backspace` для удаления символов
- Команда `page <номер>` переключает между страницами вывода

## Доступные команды

| Команда                | Описание                                  |
|------------------------|------------------------------------------|
| `help`                 | Показать список доступных команд         |
| `clear`                | Очистить терминал                        |
| `setup/confidence.bat` | Запустить процесс инициализации системы  |
| `scan`                 | Выполнить сканирование сети              |
| `decrypt`              | Запустить процесс дешифровки             |
| `page <номер>`         | Перейти на страницу вывода               |
| `exit`                 | Выйти из программы                       |

## Особенности реализации

1. **Прогресс-бар**:
   - Появляется при выполнении `setup/confidence.bat`
   - Автоматически заполняется до 100%
   - Через 2 секунды после завершения исчезает
   - Отображает процент выполнения и статус

2. **Двоичный дождь**:
   - Случайная генерация потоков из 0 и 1
   - Разная скорость падения символов
   - Эффект постепенного исчезновения символов
   - Динамическое обновление позиций

3. **Система вывода**:
   - История последних 100 команд
   - Пагинация для просмотра длинных выводов
   - Мигающий курсор ввода
   - Подсветка вводимых команд

## Требования

- Python 3.6+

- Шрифт Courier New (включен в проект)
